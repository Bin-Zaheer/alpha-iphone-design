# Alpha Design — Interior Home Website

A clean, premium single-page interior design site built with the Next.js App Router and Tailwind CSS.

## Stack

- Next.js 16.3.6
- React 19.3.0
- Tailwind CSS 4.3.3
- TypeScript

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes

- The supplied Alpha Design logo is included at `public/logo.png`.
- Interior imagery uses optimized Unsplash image URLs so the project stays lightweight.
- Main sections: Home, About, Services, Projects, Testimonials, FAQs, Contact, Footer.
- FAQ accordions and the responsive mobile navigation are interactive.
